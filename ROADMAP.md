# Roadmap: Network Guard / NetManager

## 📌 Текущая версия: v3.0 (refactored)

Ниже — список возможных улучшений, новых возможностей и технологий,
которые можно внедрить в проект.

---

## 1. 🛡 Обход защиты жертвы

- [x] **DHCP Spoofing** ★  
  Обход статического ARP (`arp -s`). Выдаём жертве наш IP как шлюз через DHCP.  
  Жертва получает новые настройки, ARP-таблица не сканируется — защита бесполезна.
- [ ] **ICMP Redirect (улучшенный)**  
  Уже есть в коде, но Windows 10+ часто игнорирует.  
  Добавить множественные Redirect-пакеты с разных IP.
- [ ] **DHCP Starvation**  
  Исчерпать пул адресов на DHCP-сервере, чтобы жертва не могла получить новый IP.
- [ ] **Обнаружение Dynamic ARP Inspection (DAI)**  
  Проверка: доходят ли ARP-пакеты до жертвы. Если нет — DAI включён.
- [ ] **Обход DAI через MAC-клонирование**  
  Если известен MAC коммутатора/роутера — подделывать ARP от его имени.

## 2. 🔐 Безопасность и стелс

- [ ] **Рандомизация MAC-адреса атакующего**  
  Scapy меняет source MAC при каждой отправке ARP — детект через `arp -a` невозможен
- [ ] **ARP-спуфинг с задержкой (jitter)**  
  Случайные паузы между пакетами — не паттерн для IDS
- [ ] **Обход ARP-детекции (XArp, NetCut)**  
  Добавить Gratuitous ARP только при активности цели
- [ ] **SSLStrip / HTTPS Downgrade**  
  Перехват HTTPS → HTTP с помощью `mitmproxy` или собственного прокси
- [ ] **HSTS Bypass**  
  Отлов доменов без HSTS preload

## 3. 📡 Сетевые возможности

- [ ] **Поддержка IPv6**  
  Neighbor Advertisement Spoofing (NDP)
- [ ] **Сканирование нескольких подсетей**  
  Автоопределение всех активных сетевых интерфейсов и их подсетей
- [ ] **Обнаружение шлюза через DHCP**  
  Парсинг DHCP Offer вместо `route print`
- [ ] **Wi-Fi deauth-атака**  
  Отправка Deauth-пакетов к точке доступа
- [ ] **Beacon-флуд**  
  Создание фейковых точек доступа для сбора клиентов

## 4. ⚡ Производительность

- [ ] **WinDivert-форвардинг** ★  
  Пересылка трафика через kernel-mode драйвер вместо Scapy (user-space).  
  Скорость: 200-500 Mbps вместо 10-30 Mbps.  
  Scapy остаётся только для анализа (DNS, TLS, OS fingerprinting).
- [ ] **Мониторинг без форвардинга (режим "только анализ")**  
  Когда скорость критична — только перехватываем копию трафика, не влияя на поток.
- [ ] **AsyncIO + Scapy**  
  Асинхронный сниффер без блокировки потоков.

## 5. 📊 Анализ трафика

- [ ] **HTTP(S) Man-in-the-Middle через mitmproxy**  
  Полный перехват и расшифровка трафика с подменой сертификата
- [ ] **Packet Logger (PCAP)** ★  
  Сохранение перехваченных пакетов в `.pcap` для анализа в Wireshark
- [ ] **Сбор паролей (HTTP Basic, FTP, Telnet)**  
  Регулярки на raw-трафик
- [ ] **Фильтрация по протоколам**  
  Показать только HTTP / DNS / TLS / ICMP
- [ ] **Статистика: топ-сайты, топ-протоколы**  
  GUI-графики на основе захваченных данных

- [ ] **MAC Changer**
